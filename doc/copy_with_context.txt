1. OVERVIEW                                   *copy_with_context-overview*

This plugin allows you to copy lines with file path and line number context.
Useful for sharing code snippets with context for other developers.

==============================================================================
2. MAPPINGS                                   *copy_with_context-mappings*

By default, the following mappings are provided:

<leader>cy  - Copy with relative path (normal/visual mode)
<leader>cY  - Copy with absolute path (normal/visual mode)
<leader>cr  - Copy with remote repository URL (normal/visual mode)
<leader>cp  - Copy with absolute path + line fragment (normal/visual mode)

==============================================================================
3. CONFIGURATION                        *copy_with_context-configuration*

There is no need to call setup if you are ok with the defaults.

>
  require('copy_with_context').setup({
    mappings = {
      relative = '<leader>cy',
      absolute = '<leader>cY',
      remote   = '<leader>cr',
      ghpath   = '<leader>cp',
    },
    formats = {
      default = '# {filepath}:{line}',
      remote  = '# {remote_url}',
    },
    output_formats = {
      ghpath = '{filepath}#{line_fragment}\n{copied_text}',
    },
    trim_lines = false,
  })
<

==============================================================================
4. FORMAT VARIABLES                   *copy_with_context-format-variables*

You can use the following variables in format strings:

{filepath}      - The file path (relative or absolute depending on mapping)
{line}          - Line number or range (e.g., "42" or "10-20")
{linenumber}    - Alias for {line}
{line_fragment}  - Provider-specific line fragment (e.g., "L42" or "L10-L20")
{remote_url}    - Repository URL (GitHub, GitLab, Bitbucket)
{copied_text}   - The selected text (used with output_formats)

==============================================================================
5. EXAMPLES                                 *copy_with_context-examples*

1. Copy current line with relative path:
   - Press `<leader>cy` in normal mode.

Output example:
>
  <% posts.each do |post| %>
  # app/views/widgets/show.html.erb:4
<

2. Copy current line with absolute path:
   - Press `<leader>cY` in normal mode.

Output example:
>
  <% posts.each do |post| %>
  # /Users/zh/dev/project_name/app/views/widgets/show.html.erb:4
<

3. Copy with line fragment (ghpath):
   - Press `<leader>cp` in normal mode.

Output example:
>
  /Users/zh/dev/project_name/app/views/widgets/show.html.erb#L4
  <% posts.each do |post| %>
<

4. Visual selection with line range:
   - Select lines in visual mode.
   - Press `<leader>cp`.

Output example:
>
  /Users/zh/dev/project_name/app/views/widgets/show.html.erb#L4-L6
  <% posts.each do |post| %>
      <%= post.title %>
  <% end %>
<
